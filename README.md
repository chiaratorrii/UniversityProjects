# University Projects

Welcome to **UniversityProjects** 🎓  
This repository contains a collection of academic projects completed during my university studies. The projects span topics such as statistical modeling, econometrics, text mining, and applied data analysis, and reflect my work across different courses and thesis projects, with a strong focus on quantitative methods and data-driven insights.



## Repository Structure

The repository currently includes the following projects:

- **Applied Statistical Modelling Projects**  
  A collection of projects focused on applied statistical models, including Bayesian statistical models.

- **Bachelor’s Thesis – Women in STEM**  
  Undergraduate thesis exploring gender representation in STEM (Science, Technology, Engineering & Mathematics). Title: "Employment opportunities and university degree choice: an analysis
on the underrepresentation of women in STEM".

- **NEET and BES Indicators**  
  Socio-economic analysis based on NEET indicators and *Benessere Equo e Sostenibile* (Equitable and Sustainable Wellbeing) metrics.

- **Text Mining Project**  
  Project applying text mining techniques for extracting insights from unstructured textual data. In particular, we applied sentiment analysis and topic modelling on scraped reviews of a product available on Amazon.

- **Workplace Violence and Absenteeism Project**  
  Empirical labor economics study investigating the relationship between workplace violence and employee absenteeism.

Each folder contains the relevant code, documentation, and (where applicable) datasets or reports.



## Purpose of This Repository

This repository is intended to:

- Document and showcase my academic work
- Provide examples of practical applications of statistical and data analysis methods
- Demonstrate technical and methodological skills developed during my studies
